# SURYAKIRAN T S — Cyber Defense Intelligence & Digital Forensics Portfolio

> A futuristic, high-performance interactive cybersecurity portfolio featuring 3D holographic project chambers, deterministic neural dispersion particle assembly, and defensive security operations telemetry.

---

## ⚡ Key Highlights & Cyber Capabilities

- 🧬 **Neural Dispersion & Particle Portrait Engine**: Interactive HTML5 Canvas assembling thousands of cyber particles into HD biometric portrait telemetry with continuous deterministic scroll dispersion.
- 🎡 **3D Holographic Rotary Project Chamber**: Interactive 3D cylindrical rotary wheel displaying defensive operations (`PhishGuard`, `FileSentinel`, `CyberToolkit`, `CipherTrace`) with smooth radar pedestal animations and instantaneous arranged layout sorting.
- 🛡️ **Defensive Tool Arsenal**: High-density interactive matrix showcasing 12 essential blue-team & DFIR tools with authentic brand logos (Splunk, Wazuh, Wireshark, Nmap, Burp Suite, Autopsy, FTK Imager, Kali Linux, Python, Metasploit, VirusTotal, Hashcat).
- 📟 **Futuristic Command Terminal**: Terminal HUD displaying system diagnostic sequences (`whoami`, active defense telemetry, incident response metrics).
- 🧱 **Firewall Defender SOC Mini-Game**: Integrated canvas-based arcade simulator simulating packet inspection and threat deflection.
- 🌐 **GitHub Pages Ready**: Optimized, responsive, zero-external-build-dependency static web architecture.

## 🚀 Quick Start / Local Deployment

### Option 1: VS Code Live Server
1. Open this folder in **Visual Studio Code**.
2. Click **Go Live** on the bottom status bar (or right-click `index.html` and select **Open with Live Server**).
3. Access at `http://127.0.0.1:5500/`.

### Option 2: Python HTTP Server
```bash
python -m http.server 8000
```
Open your browser and navigate to `http://localhost:8000/`.
